# MAYA Agentic Harness Wiki

Welcome to the official documentation for the MAYA Agentic Harness.

## What is MAYA?

MAYA is a local-first personal AI command center and agentic harness. It combines a JARVIS-style dashboard with an agent runtime designed for systems that prove what happened.
